# Don't use shorthand syntax

Method shorthand in interfaces lets an implementation narrow a parameter type without TypeScript complaining, which can blow up at runtime, especially in inheritance scenarios. This talk shows the pitfall and why declaring methods as function-typed properties keeps the checks strict.
